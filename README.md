# 猛人灵修（Mengren Lingxiu）

> 作者：longpeng1413 和 Claude

一个 Windows 上的**灵修 / 心灵成长老师蒸馏软件**：把一位老师的课程音视频、文章、对话记录整理好，蒸馏成观点库、语录、比喻和故事、问答和老师画像，然后像向老师本人请教一样，和「AI 按老师资料模拟的他」对话——回答里讲过的内容都带出处，点一下就能回到那节课那一秒、或那篇文章那一段。

它是从 [猛人学习](https://github.com/longpeng1413/mengren-learning)（交易课程的字幕整理 + 老师蒸馏）1.8.10 分出来的独立软件：猛人学习的功能全部保留（识别字幕、AI 校对、书籍整理、剪藏到 Obsidian……），只把「老师蒸馏」改成适合灵修老师的做法，并支持文字资料。

## 为什么要专门做一个灵修版

交易老师的蒸馏重点是「观点 + 适用条件」。灵修老师不一样，他最宝贵的往往不是道理本身，而是：

- **原话**：一句点醒人的话，换个说法就没了力量；
- **比喻和故事**：他总用来讲某个道理的那个比喻、那个故事；
- **怎么回应一个人的困惑**：学员哭着来问时，他是先接住情绪、先反问、还是直接点破；用什么语气、什么节奏；
- **修法**：具体怎么练、什么时候练、要注意什么。

所以猛人灵修逐份提取时多了「原话」「比喻和故事」「问答」三类，老师画像重点写「他怎么回应一个人的困惑」「语录」「说话风格」，对话时要求 AI 像老师那样说话、少用 AI 腔。

## 和猛人学习的关系

猛人灵修是**独立的软件**，从猛人学习 1.8.10 分出来，以后各自改进。灵修的课程、书籍都在猛人灵修里整理、蒸馏。

| | 猛人灵修 | 猛人学习 |
|---|---|---|
| 设置、媒体库、老师、对话记录 | `%APPDATA%\猛人灵修\` | `%APPDATA%\猛人学习\` |
| 字幕和整理结果 | 视频旁边的 `视频名.mp4.猛人灵修.json` | 视频旁边的 `视频名.mp4.猛人学习.json` |
| Obsidian 库 | 灵修知识库（例如 `C:\猛人灵修`） | 交易知识库 |

- **猛人学习里已经识别好的课，不用重新识别**：在猛人灵修里打开这节课时，如果还没有 `.猛人灵修.json`，会把旁边的 `.猛人学习.json` 读过来当起点（不带猛人学习的剪藏记录），保存时只写 `.猛人灵修.json`。**猛人学习的文件一律不写、不改名、不删。**
- 第一次打开猛人灵修时，会从猛人学习**只读复制** AI 登录（ChatGPT 账号）、豆包语音密钥、代理和「哪件事用哪家 AI」的选择；媒体库、老师、术语表、Obsidian 位置、播放进度都不带。之后两边的设置互不影响。

## 下载和安装

1. 到 [Releases](https://github.com/longpeng1413/mengren-lingxiu/releases) 下载最新的 `mengren-lingxiu-版本号-windows-with-ffmpeg.zip`，解压到任意文件夹（不要放在 C:\Program Files 这类需要管理员权限的地方）。压缩包已经附带 ffmpeg，不用另外安装。
2. 双击 `猛人灵修.exe`。整个文件夹要放在一起，不能只拷 exe。
3. 程序没有数字签名，第一次打开时 Windows 或安全软件可能会提示，选择允许即可。

运行环境：Windows 10 / 11（64 位）。界面用的是系统自带的 Edge WebView2，Windows 11 已内置；Windows 10 如果打不开，请先安装 [WebView2 运行时](https://developer.microsoft.com/microsoft-edge/webview2/)。

## 第一次使用

1. 打开「设置」（右上角齿轮）：
   - **AI 服务**：如果这台电脑上用过猛人学习，豆包密钥和其他 API Key 已经带过来了；ChatGPT 要在这里自己登录一次（推荐「ChatGPT（官方登录）」；两个软件共用一份登录会互相挤掉线，所以不带过来），或填 Claude、Gemini、DeepSeek 等的 API Key。「每项 AI 工作」里每一项（校对、蒸馏、老师对话……）都能单独选服务、模型和思考强度。
   - **字幕识别**：中文默认用**本机识别**（免费、不联网；第一次用时自动下载约 240 MB 的模型，电脑上有猛人学习或猛人快传下好的就直接用）。术语多的课可以在媒体库文件夹的「⋯」里设成豆包。
   - **Obsidian**：选你的灵修知识库（例如 `C:\猛人灵修`）。默认：课程剪藏到 `课程剪藏/老师名/`，书籍剪藏到 `书籍剪藏/`，老师蒸馏结果写到 `灵修老师/老师名/`，圆桌讨论和主题蒸馏写到 `灵修主题/`，新老师的术语表建在 `灵修术语表/`。
2. 在左侧媒体库点「＋文件夹」，把一位老师的课程、文章、对话记录所在的文件夹加进来。音视频要先有字幕：猛人学习里识别过的会读过来直接用；没识别的点开它，点「一键整理」或「生成字幕」。
3. 左栏顶上切到「老师」，点人像加号 →「从媒体库的课和文章蒸馏一位新老师」，填老师名字、选文件夹、勾选资料，点「开始蒸馏」。在后台做，做完就能和他对话。

## 老师蒸馏

1. **逐份提取观点库**：每份资料单独让 AI 读完原文，拆成：
   - 观点、修法（练习）、定义（老师对某个说法的解释）；
   - **原话**（语录，照录）；
   - **比喻和故事**（内容 + 他用来讲什么）；
   - **问答**（学员问了什么、老师怎么回应——尽量用原话、保留回应的步骤、写明回应方式：先接纳、反问、点破、讲故事、带着做练习……）；对话记录类资料最重要的就是这部分；
   - 老师自述（经历、修行经历、立场、课程安排），术语，可以拿去实践的，存疑（识别可能有错、前后矛盾的地方）。
2. **合并成课程蒸馏**：一句话、核心教导体系、核心观点、修法、他反复强调的、常用比喻和故事、前后说法不一致的、没讲到的、可以实践的。资料很多时先分组小结再合并。
3. **写老师画像**：第一节是软件固定写的对话规则（见下面），后面是 AI 写的：他是谁、核心信念、**他怎么回应一个人的困惑**、怎么思考、**语录**、**常用的比喻和故事**、**说话风格**、反对什么、没讲的、回答示范（其中一个是情绪很痛苦的提问）。
4. 三份文件写进 Obsidian：`灵修老师/老师名/01、观点库（逐节提取）.md`、`02、课程蒸馏.md`、`03、老师画像（对话用）.md`。都是 AI 写的，状态标着「待作者审核」，你可以在 Obsidian 里改，对话时用的就是改过的。

**出处**：音视频写成 `S02 19:54`（第 2 份资料 19 分 54 秒）；文字资料写成 `S03 第12段`（每个非空行算一段，对话记录一般一句一行；PDF 是「第几页」）。观点库编号：`S02-21` 观点、`S02-Y3` 原话、`S02-B1` 比喻和故事、`S02-W1` 问答、`S02-A1` 自述。编号一旦分配就不变，老师有了新资料只提取新的。

**对话规则**（老师画像第一节，程序固定写）：只用资料里的教导说话并标出处；资料没讲的标「AI 推测」并说清从哪几条推出来；不掺 AI 自己的观点；像老师那样说话，先回应这个人再讲道理，不用 AI 腔；被问到时照实说「我是 AI 按老师资料模拟的，不是老师本人」，不替老师做承诺；**对方流露严重痛苦或自伤念头时，先关心，建议联系身边的人和专业心理援助（当地心理援助热线、医院心理科），不只用灵性道理带过，也不说「这是你的业力」这类让人更自责的话**。灵性投资类的老师，不限制谈具体的买卖。

**圆桌讨论、主题蒸馏**：几位老师一起回答同一个问题（各自只用自己的资料，AI 总结共识和分歧），或比较几位老师怎么讲同一个主题；收藏和结果写进 Obsidian 库的 `灵修主题/主题/`。

## 默认设置和猛人学习不同的地方

- **不写课程重点**：灵修课一般只识别、校对，直接蒸馏老师。媒体库文件夹「⋯」菜单里「这里的课不写课程重点」默认打着 ✓，点掉就照常写。
- **媒体库也列 txt / md**：文章、对话记录可以直接选作蒸馏来源；和音视频同名的 txt / md（导出的文字稿）不列；Obsidian 库文件夹（里面有 `.obsidian` 的）不列。没当书整理过的 txt / md 不标「未整理完」。
- **剪藏位置**：课程剪藏到 `课程剪藏/`，书籍剪藏到 `书籍剪藏/`；新老师的术语表建在 `灵修术语表/老师名术语表.md`。
- **书的提炼笔记是灵修版**：和猛人学习一样不设固定栏目，但作者的原话照录、比喻和故事写完整、书里的问答写清作者怎么回应、修习方法按步骤写进「照着做」，篇幅约原文的 1/3（猛人学习是 1/5）；全书总览多一节「代表性的原话」。

## 从猛人学习同步过来的功能（1.1.0）

2026-11-03 把猛人学习 1.8.12～1.9.0 里两边都用得上的功能同步过来了：

- **书籍**：原书、目录、整理笔记三列，每列能隐藏；整理笔记可以切到「AI 对话」问这一章或整本书（AI 读原文回答，页码能点）；「朗读原文」；分章和原书目录一致（前言、各部分开篇、附录单独成篇，按部分分组）；扫描书一键「识别文字（OCR）」（Windows 自带，本机、免费）；笔记里直接显示原书的图；书的文字设置。
- **左上角「书籍 / 课程 / 老师」**：书和音视频分开列。
- **课程重点**：每条旁边有小图标（编辑、上移、下移、并到上一条、拆分、删除），改某一条时 Enter 加一条、Tab 缩进，每一步都能撤销；手动「插入截图」；「打印」「导出 PDF」（每页印页眉：日期、课程名、页码；「带时间」开关）。
- **字幕**：「打印」「导出 PDF」；插的截图能上下移动、编辑（1.6.0 起）、调大小。
- **布局**：视频、字幕、AI 区都能隐藏；标题栏按钮改成小图标，提示一句话。
- **检查更新和自动更新**：「设置 → 关于与数据 → 检查更新」，有新版本时点「下载并更新」：软件从 GitHub 下载新版本（不含 ffmpeg），核对无误后先保存、退出，换上新版本再自动打开；新版本打不开时自动退回原来的版本，设置、字幕、缓存都不受影响。下载不了时点「去下载页」手动下载。
- **使用说明**按界面版块重排；字幕区、课程重点区的「?」只讲这一块。

## 数据和隐私

| 内容 | 位置 | 能不能删 |
|---|---|---|
| 字幕、对话记录、字幕历史版本 | 视频旁边的 `视频名.mp4.猛人灵修.json` | 删了字幕就没了 |
| 设置、API 密钥、ChatGPT 登录、老师档案、媒体库、播放进度 | `%APPDATA%\猛人灵修\`（都很小） | 不要删；换电脑用「导出设置」 |
| 老师工作台的对话记录、每份资料的蒸馏结果 | `%APPDATA%\猛人灵修\mentors\` | 不要删（在软件里可以删对话、移除老师） |
| 圆桌讨论、主题蒸馏记录 | `%APPDATA%\猛人灵修\roundtables\`、`topics\` | 不要删（在软件里可以删） |
| 整理任务记录（最多 300 条） | `%APPDATA%\猛人灵修\tasks\` | 可以删 |
| 覆盖前的备份（蒸馏结果每位老师 20 份、对话精选 30 份、术语表 30 份、每日数据快照 30 天） | `%APPDATA%\猛人灵修\backups\` | 可以删 |
| 保存时用的锁文件、「正在整理」标记 | `%APPDATA%\猛人灵修\locks\` | 不用管，自动清理 |
| 缓存（转换后的视频、抽出的音频、截图） | 软件文件夹里的 `缓存（可随时删除）` | 可以随时删除 |
| 日志 | 软件文件夹里的 `日志（可随时删除）` | 可以随时删除 |

- 软件没有服务器，不收集任何数据。音频只会发给你选择的识别服务，字幕和文章只会发给你选择的 AI 服务。
- API 密钥只保存在本机，日志里不记录密钥。
- 缓存自动清理（软件启动时、命令行整理前）：抽出的音频保留 3 天，转换后的视频 30 天没打开过就删（总量最多 5GB），截图 30 天没用过就删。日志最多 4 个文件、每个 2MB。「设置 → 关于与数据」里能看到占了多少空间、一键清空。
- 和 AI 老师的对话不能代替真人的陪伴、心理咨询和医疗。

## 让 AI Agent 自动整理（命令行）

从源码运行时，可以让 Claude Code、Codex 这类 AI Agent 调用猛人灵修整理课程（等于在软件里点「一键整理」，不剪藏、不蒸馏）：

```bat
lingxiu.cmd process --course 某某老师 --todo --json
```

完整说明见 [docs/命令行.md](docs/命令行.md)。

## 从源码运行

需要 Python 3.12 以上（开发用的是 3.14）和 ffmpeg（`winget install Gyan.FFmpeg`）。

```bat
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt

rem 运行
.venv\Scripts\python app\main.py

rem 测试：后台、Agent 和命令行、媒体库（不联网，识别和 AI 用假的）
.venv\Scripts\python tests\test_backend.py
.venv\Scripts\python tests\test_agent.py
.venv\Scripts\python tests\test_library.py

rem 界面测试（会弹出一个窗口自动操作；加 --exe 测打包好的版本）
.venv\Scripts\python tests\run_ui_test.py

rem 打包：输出到 dist-next，再双击「更新到新版.bat」换进 dist
.venv\Scripts\python build.py
```

蒸馏相关的代码在 `app\core\distill.py`（逐份提取、合并、老师画像、提示词）、`app\core\mentor.py`（观点库解析、文字资料按段落编号、对话）、`app\core\roundtable.py`（圆桌讨论、主题蒸馏），界面在 `app\web\mentor.js`、`round.js`。维护约定见 [AGENTS.md](AGENTS.md)。
